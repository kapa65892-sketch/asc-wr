# ASC-WR

**ASC-WR** is an early personal research prototype and the beginning of a product vector: a local, low-power, peripheral witness of causal drift.

The first practical application is driver pre-sleep drift detection with a smartphone on the body. The wider idea is larger: a phone, smart talisman and other body-worn sensors may become distributed witnesses of early drift toward danger in a person, mechanism, robot or nearby environment.

## Current Prototype

- `asc_wr_phone_live_v5.html` - current phone HTML prototype.
- Runs in a mobile browser over HTTPS.
- Uses phone IMU, optional microphone features and voice/audio event notes.
- Saves local CSV logs and optional audio for laboratory analysis.
- Magnetometer branch was removed.

## Core Idea

Observe the drift. Warn if possible. Preserve the path if not.

ASC-WR is not presented as a finished safety product or certified medical/driver-monitoring system. It is an open laboratory beginning: a simple local observer that tries to detect early deviation before a critical event and preserve the causal path if the event unfolds.

## Smart Talisman Vector

The phone may become the central head of a distributed sensing system. A smart talisman, pendant, ring, watch, ear clip or jewelry-mounted sensor may become peripheral organs of this phone-head.

One possible product direction is a standard replaceable sensor core that can be inserted into practical jewelry: inexpensive, precious, inherited, handmade, male/female/child, with or without stones. The jewelry remains personal and cultural; the sensor core can be updated.

See: `SMART_TALISMAN_VECTOR_RU.md`
